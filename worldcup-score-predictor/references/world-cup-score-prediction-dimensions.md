# 世界杯足球比分预测分析维度

> 本文件负责解释分析方法和判断逻辑；机器执行清单以 `config/dimensions.json` 为准。`SKILL.md` 只定义执行流程。

本文档用于系统化分析和预测世界杯足球比赛比分。核心原则是：**不要只依赖球队排名和整体名气，要从球员状态、球员类型、风格克制、关键对位、进球路径、比赛阶段、临场变量和巨星超额能力综合判断。**

本文档已吸收以下复盘经验：

- 比利时 1-1 埃及：低估弱队持续进攻和平局风险。
- 伊朗 2-2 新西兰：低估弱队第二球能力和首战混乱指数。
- 法国 3-1 塞内加尔：低估强队下半场提速、替补冲击和巨星第三球能力。
- 伊拉克 1-4 挪威：低估高空/定位球错位、前锋压迫制造进球和补时混战。
- 阿根廷 3-0 阿尔及利亚：高估弱队进球路径，低估强队零封能力和巨星健康状态。

---

## 一、核心预测原则

1. 先判断总进球区间，再预测具体比分。
2. 球队排名只作为基础盘，不能直接决定比分。
3. 必须评估关键球员的当前状态、实力、类型和是否首发。
4. 必须判断球队 A 的弱点是否正好是球队 B 的强项。
5. 强队第二球能力、第三球能力和弱队第二球能力都要单独分析。
6. 强队防守脆弱度要和强队进攻能力同等重要。
7. 小组赛首轮不一定是小球，要同时评估谨慎指数和混乱指数。
8. 平局不能只看 0-0 和 1-1，也要判断 2-2 的可能。
9. 巨星状态确认健康时，要允许其突破团队均值，把比分从 2 球区间推到 3-4 球。
10. 社媒和队内关系只作为修正项，不能替代比赛数据。
11. 输出多个比分，并说明每个比分成立的触发条件。

## 二、赛前基础层

| 维度 | 重点看什么 | 作用 |
|---|---|---|
| FIFA 排名 / Elo | 长期实力差距 | 判断基础胜负倾向 |
| 阵容身价与球员级别 | 五大联赛主力、核心球星、门将质量 | 判断球队上限 |
| 大赛经验 | 世界杯、洲际杯、淘汰赛经验 | 判断抗压能力 |
| 替补深度 | 是否有后手改变比赛 | 判断最后 30 分钟走势 |
| 教练稳定性 | 是否长期执教、体系是否成熟 | 判断战术执行力 |
| 阵容年龄结构 | 老将比例、年轻球员经验、体能储备 | 判断后程稳定性 |
| 首战压力 | 热门球队是否背负必须赢球压力 | 判断保守或混乱概率 |

## 三、球员个体状态与实力层

预测比分时，需要对双方关键球员逐个评估，不能只看球队整体排名。

| 维度 | 重点看什么 | 对比分影响 |
|---|---|---|
| 是否首发 | 核心攻击手是否进入首发 | 直接影响弱队/强队进球路径 |
| 预计出场时间 | 能踢 90 分钟还是只能替补 20-30 分钟 | 影响全场进攻稳定性 |
| 近期出场时间 | 俱乐部和国家队是否稳定首发 | 判断比赛状态 |
| 近期进球 / 助攻 | 前锋、边锋、中场创造力 | 判断直接威胁 |
| 伤病恢复阶段 | 刚复出、带伤、体能不足 | 降低持续输出 |
| 关键数据 | 射门、射正、关键传球、抢断、拦截、解围 | 判断真实贡献 |
| 对抗能力 | 速度、力量、高空球、脚下技术 | 判断对位胜负 |
| 大赛表现 | 是否在高压比赛中稳定 | 判断关键球能力 |
| 心理状态 | 红黄牌风险、舆论压力、社媒情绪 | 判断失误和纪律 |
| 年龄与体能 | 老将下滑、年轻球员经验不足 | 判断下半场变化 |

### 关键位置评估

| 位置 | 重点看什么 |
|---|---|
| 门将 | 扑救、出击、脚下、失误率、传中处理、脱手风险 |
| 中卫 | 速度、防空、转身、盯人、出球、抗压能力 |
| 边后卫 | 回追、传中、身后空间、一对一防守 |
| 后腰 | 覆盖、拦截、抗压出球、保护中卫 |
| 中场核心 | 组织、直塞、控节奏、摆脱压迫 |
| 边锋 | 一对一、内切、传中、反击速度 |
| 中锋 | 终结、支点、头球、压迫、禁区触球、制造混战 |

## 四、球员类型结构层

球员名气不等于战术价值，必须判断类型是否互补，以及是否能针对对手弱点。

| 球员类型 | 代表能力 | 影响 |
|---|---|---|
| 速度型边锋 | 冲身后、一对一突破 | 克制高位防线和慢中卫 |
| 支点型中锋 | 头球、背身、二点球 | 克制防空弱、防线矮的球队 |
| 终结型前锋 | 禁区嗅觉、射正率 | 提高低机会转化率 |
| 压迫型前锋 | 逼抢门将、中卫，制造失误 | 增加非传统进球路径 |
| 组织型中场 | 控节奏、直塞、转移 | 提高阵地战效率 |
| 破坏型后腰 | 拦截、覆盖、犯规控制 | 降低对手核心威胁 |
| 出球型中卫 | 后场推进、长传 | 破解高压 |
| 防守型边卫 | 单防、回追 | 限制对方边锋 |
| 进攻型边卫 | 插上、传中 | 提高边路进攻，但增加身后风险 |
| 高空型中卫 | 防空、定位球 | 克制传中和长传冲吊 |
| 扑救型门将 | 反应、近距离扑救 | 提高小比分守平概率 |

## 五、关键对位层

关键对位决定比赛如何被打开，也决定弱队是否有爆冷或打平能力。

| 对位 | 重点判断 |
|---|---|
| A 队边锋 vs B 队边后卫 | 能否一对一突破？边后卫是否怕速度？ |
| A 队中锋 vs B 队中卫 | 支点、头球、力量、禁区卡位是否占优？ |
| A 队压迫型前锋 vs B 队门将 / 中卫 | 是否能逼出传球失误、脱手或乌龙？ |
| A 队前腰 / 中场核心 vs B 队后腰 | 能否获得转身和直塞空间？ |
| A 队高压 vs B 队门将 / 中卫出球 | 是否会逼出失误？ |
| A 队定位球高点 vs B 队防空 | 是否有明显身高或力量优势？ |
| A 队反击速度 vs B 队防线高度 | 是否存在身后空间？ |
| A 队边后卫压上 vs B 队反击边锋 | 是否会被打身后？ |
| A 队门将出击 vs B 队传中 / 长传 | 是否容易判断失误？ |

如果出现明显错位，要直接修正比分：

- 强队排名高，但中卫慢；弱队有高速边锋：弱队进球概率上调。
- 强队控球强，但缺少中锋；弱队低位防守好：强队第二球概率下调。
- 弱队排名低，但定位球强；强队防空差：弱队至少一球概率上调。
- 强队有压迫型中锋，对手门将/中卫出球差：强队第三球概率上调。
- 强队高空优势明显，对手防空差：3-1、4-1、4-0 进入候选区间。

## 六、历史球队风格层

球队风格有延续性，不能只看当期排名。

| 风格 | 重点看什么 | 比分倾向 |
|---|---|---|
| 传控型 | 控球、短传、阵地战 | 可能压制，但怕反击 |
| 防守反击型 | 低位、速度、转换 | 容易打出小胜或逼平 |
| 高压逼抢型 | 前场压迫、抢开局 | 容易早球，也容易后程掉速 |
| 长传冲吊型 | 高点、二点球、身体对抗 | 容易制造混乱和定位球 |
| 边路传中型 | 边后卫插上、边锋传中 | 依赖中锋和防空对位 |
| 中路渗透型 | 前腰、肋部配合 | 怕密集防守和强后腰 |
| 定位球强队 | 角球、任意球套路 | 小比分比赛中特别关键 |
| 慢节奏控场型 | 降速、减少回合 | 偏低比分 |
| 开放转换型 | 攻守转换快 | 容易出现 2-2、3-2 |

需要重点追问：

- 这支球队历史上是否容易打平？
- 是否经常先进球后保守？
- 是否经常被反击打穿？
- 是否面对低位防守缺少办法？
- 是否定位球长期强或长期弱？
- 是否具备下半场调整后突然提速的传统？

## 七、风格克制矩阵

预测前必须判断：球队 A 的弱点是否正好是球队 B 的强项。

| A 队弱点 | 如果 B 队强项是 | 修正方向 |
|---|---|---|
| 中卫慢 | 高速反击、直塞身后 | B 队进球概率上调 |
| 防空差 | 高中锋、角球、传中 | B 队定位球进球概率上调 |
| 边后卫压上大 | 速度型边锋 | B 队反击进球概率上调 |
| 后腰覆盖差 | 前腰、肋部渗透 | B 队中路机会增加 |
| 门将出击差 | 传中、长传冲吊 | B 队高空球威胁上调 |
| 门将/中卫出球差 | 前锋高压逼抢 | B 队压迫进球概率上调 |
| 破密防弱 | 低位防守纪律强 | A 队第二球概率下调 |
| 出球差 | 高压逼抢 | A 队失误丢球概率上调 |
| 体能差 | 高节奏冲击、替补快马 | 后段丢球概率上调 |
| 情绪不稳 | 强对抗、裁判严 | 红黄牌风险上调 |

## 八、近期状态层

| 维度 | 重点看什么 | 作用 |
|---|---|---|
| 最近 5-10 场战绩 | 胜平负、对手质量 | 判断当前状态 |
| 近期进球趋势 | 场均进球、射正、重大机会 | 判断进攻热度 |
| 近期失球趋势 | 场均失球、被射门、被反击 | 判断防守稳定性 |
| 面对强队表现 | 是否能抗压、反击是否有效 | 判断弱队爆冷概率 |
| 面对弱队表现 | 是否能破密防 | 判断强队是否能赢两球以上 |
| 领先 / 落后表现 | 领先能否控场，落后能否反扑 | 判断平局与逆转概率 |
| 下半场表现 | 是否常在 60 分钟后提速或崩盘 | 判断第三球和尾段进球 |

## 九、进球分布层

比分预测的核心不是谁强，而是谁更可能进几个球。

| 维度 | 重点看什么 | 作用 |
|---|---|---|
| xG / xGA | 预期进球、预期失球 | 判断真实攻防质量 |
| 射门数量 | 是否能持续制造机会 | 判断进攻压力 |
| 射正数量 | 是否真正威胁球门 | 判断进球概率 |
| 重大机会 | 单刀、空门、禁区内机会 | 判断比分上限 |
| 禁区触球 | 是否只是外围倒脚 | 判断破密防能力 |
| 定位球威胁 | 角球、任意球、头球、二点球 | 判断小比分破局点 |
| 压迫制造机会 | 前锋逼抢、门将脱手、后卫失误 | 判断非常规进球 |
| 点球 / 乌龙 / 红牌概率 | 禁区压力、裁判尺度、防守慌乱 | 判断非常规进球 |

---

## 十、强队第二球能力

强队赢不赢，很多时候取决于是否能打进第二球。

| 维度 | 重点看什么 | 影响 |
|---|---|---|
| 中锋状态 | 是否健康、是否首发、比赛节奏感 | 影响终结能力 |
| 核心创造者 | 组织核心是否能持续制造高质量机会 | 影响机会质量 |
| 射正率 | 射门是否转化为威胁 | 影响第二球概率 |
| 禁区内射门比例 | 是否依赖远射 | 影响进球稳定性 |
| 边路爆点 | 是否能突破双人包夹 | 影响破密防 |
| 替补冲击时间 | 核心替补能踢多久 | 不能把 20 分钟影响当成 90 分钟优势 |
| 领先后进攻意愿 | 是否继续压上或开始保守 | 判断是否会扩大比分 |

---

## 十一、强队第三球与大胜能力

这是复盘法国 3-1、挪威 4-1、阿根廷 3-0 后新增的重点维度。

| 维度 | 重点看什么 | 修正方向 |
|---|---|---|
| 巨星超额进球能力 | 姆巴佩、梅西、哈兰德等能否靠个人能力突破 xG 均值 | 把 2-1 上调到 3-1，2-0 上调到 3-0 |
| 替补冲击质量 | 替补边锋、前锋是否能制造最后 20 分钟进球 | 上调第三球概率 |
| 下半场战术调整 | 教练能否通过换位、换人、变阵改善进攻 | 上调 60 分钟后进球 |
| 对手体能掉速 | 弱队是否长期防守后下半场崩盘 | 上调强队尾段进球 |
| 门将/后卫失误 | 对手门将脱手、出球差、解围失误 | 上调 3-0、3-1、4-1 |
| 高空/定位球错位 | 强队是否有明显身高和定位球优势 | 上调 3 球以上比分 |
| 补时进球能力 | 强队是否仍持续压迫，补时是否有混战优势 | 上调 4-1、3-1 |

触发规则：

- 强队有健康巨星 + 替补深度 + 弱队防线被压制：3 球进入主预测区间。
- 强队有高空优势 + 对手防空弱：4 球进入冷门但有效区间。
- 巨星状态确认很好时，不要机械压低到 2-1 或 2-0。

## 十二、弱队第一球与第二球能力

弱队不是只能偷一个，但也不能只凭球员名气机械给一球。

| 维度 | 重点看什么 | 影响 |
|---|---|---|
| 核心攻击手是否首发 | 关键边锋/前锋是否从开局在场 | 决定弱队进球概率 |
| 核心攻击手出场时间 | 是否只是 60 分钟后替补 | 下调弱队早段进球概率 |
| 多点进攻 | 是否不只依赖一个球星或一个套路 | 提高第二球概率 |
| 运动战能力 | 是否能通过传跑打出机会 | 提高进球稳定性 |
| 反击速度 | 是否能利用强队压上身后 | 提高爆冷概率 |
| 定位球能力 | 高点、传中、二点球 | 提高偷球和连续威胁 |
| 抗压出球 | 是否能从围攻中把球摘出来 | 避免被长期压制 |
| 替补冲击 | 后手是否能制造速度或高度变化 | 提高后段进球概率 |
| 落后反弹能力 | 丢球后是否仍能组织进攻 | 提高平局和爆冷概率 |

修正规则：

- 弱队核心攻击手不首发：双方进球概率下调。
- 弱队进攻只依赖一个球星且被限制：从 2-1 修正为 2-0 或 3-0。
- 弱队有两条以上进球路径：1-1、2-2 进入主预测区间。

---

## 十三、热门球队防守脆弱度与零封能力

强队不是只分析进攻，还必须判断它会不会丢球，以及是否具备零封能力。

| 维度 | 重点看什么 | 影响 |
|---|---|---|
| 中卫转身速度 | 是否怕身后球 | 提高反击丢球概率 |
| 边后卫身后空间 | 是否压得太靠上 | 提高弱队边路机会 |
| 后腰保护 | 是否能保护中卫身前 | 影响禁区前沿防守 |
| 门将稳定性 | 出击、扑救、脚下传球 | 影响小比分结果 |
| 定位球防守 | 防空、盯人、二点球 | 提高弱队进球概率 |
| 丢球后纪律 | 是否急躁、阵型散 | 提高连续丢球风险 |
| 领先后控场 | 是否能降速、控球、减少转换 | 判断是否被追平 |
| 零封能力 | 控球压制、反抢、禁区保护、门将稳定 | 决定是否从 2-1 改为 2-0/3-0 |

零封修正规则：

- 强队中场控制强 + 弱队核心不首发：上调 2-0、3-0。
- 弱队进攻只停留在外围传导：下调双方进球概率。
- 强队能持续反抢并减少转换：弱队进球概率下调。

## 十四、战术匹配层

| 维度 | 重点看什么 | 作用 |
|---|---|---|
| 控球 vs 反击 | 强队压上是否给对手空间 | 判断双方进球 |
| 高压 vs 出球 | 能否破解逼抢 | 判断早球和失误 |
| 边路对位 | 边锋 / 边后卫强弱 | 判断突破和传中 |
| 中场控制 | 谁能控制二点球和节奏 | 判断射门数量 |
| 防线高度 | 高位线是否怕速度型前锋 | 判断反击质量 |
| 定位球对位 | 高点、防空、盯人 | 判断僵局破局 |
| 体能战术 | 是否依赖高强度逼抢 | 判断后半段掉速 |
| 变阵弹性 | 教练是否能通过换位改变局面 | 判断下半场提速 |

## 十五、比赛阶段与心理层

| 维度 | 重点看什么 | 影响 |
|---|---|---|
| 小组赛首轮谨慎指数 | 怕输、试探、保守 | 提高低比分 |
| 小组赛首轮混乱指数 | 紧张、早球、失误、节奏失控 | 提高大比分和平局 |
| 小组第二轮 | 首轮结果决定冒险程度 | 分化明显 |
| 小组第三轮 | 轮换、算分、保平 | 比分不稳定 |
| 淘汰赛压力 | 容错率低 | 提高低比分 |
| 净胜球需求 | 是否必须多进球 | 提高大比分 |
| 领先 / 落后心理 | 领先是否收缩，落后是否急躁 | 判断追平或反超 |
| 巨星里程碑/舆论压力 | 是否刺激核心球员提高射门欲望 | 上调个人进球概率 |

## 十六、平局风险指数

平局不只是 0-0 和 1-1，还要判断 2-2。

| 平局类型 | 触发条件 |
|---|---|
| 0-0 | 双方进攻弱、淘汰赛、缺少爆点 |
| 1-1 | 强队优势有限、弱队有一个明确进球路径 |
| 2-2 | 强队能进球但防线不稳，弱队有第二进球路径 |
| 3-3 | 防线崩、节奏极开放、红牌 / 点球 / 早球频繁 |

重点判断：

- 强队是否能打进第二球。
- 强队是否能打进第三球。
- 弱队是否能打进第二球。
- 双方是否都有明显防守漏洞。
- 早球后比赛是否会被打开。

## 十七、阵容与伤停层

| 维度 | 重点看什么 | 影响 |
|---|---|---|
| 中锋缺席 | 影响终结和第二球 | 降低强队进球上限 |
| 中卫 / 后腰缺席 | 影响防守稳定性 | 提高丢球概率 |
| 门将变动 | 影响低比分稳定性 | 提高意外进球 |
| 核心替补 | 只能踢 20-30 分钟 | 降低全场影响，但可能提高尾段冲击 |
| 首发默契 | 临时换阵、组合不熟 | 提高失误 |
| 老将体能 | 是否下半场掉速 | 提高后段丢球 |
| 弱队攻击核心不首发 | 进攻威胁延后或下降 | 下调弱队进球概率 |

## 二十二、动态比分触发器

赛前预测要设置“如果发生 X，则比分改判”的条件。

| 触发器 | 应如何修正 |
|---|---|
| 弱队先进球 | 从强队小胜改为 1-1 / 2-1 / 2-2 |
| 强队早早领先 | 看强队控场能力；控场弱则防 1-1 / 2-2，控场强则防 2-0 / 3-0 |
| 双方 20 分钟内都有高质量机会 | 上调总进球到 3-4 球 |
| 弱队角球连续增加 | 上调弱队进球概率 |
| 强队射门多但射正少 | 降低第二球概率 |
| 强队射正率高 | 上调第二球和第三球概率 |
| 强队边后卫频繁压上被打身后 | 上调弱队第二球概率 |
| 强队替补边锋/前锋制造连续机会 | 上调尾段第三球概率 |
| 门将脱手或后场出球失误 | 上调强队大胜概率 |
| 裁判早早出牌 | 上调点球 / 红牌 / 大比分概率 |

### 事件情景的量化改判

事件触发器不能只写“上调”或“下调”，必须给出可执行的比分迁移。以下是情景修正，不是赛前无条件加到首选比分：

| 事件 | 建议修正 | 使用条件 |
|---|---|---|
| 强队被罚下一人 | 强队预期进球下调约 0.5-0.8，弱队上调约 0.4-0.7 | 红牌发生在前60分钟时影响最大 |
| 弱队被罚下一人 | 强队预期进球上调约 0.7-1.0，第三球和第四球进入主区间 | 强队仍有足够进攻时间和替补深度 |
| 弱队被罚下两人 | 直接建立 4-0、5-0、6-0 等极端尾部，不再沿用常态总进球上限 | 两张红牌发生较早且强队持续进攻 |
| 点球或门将重大失误 | 对受益方增加一条独立进球路径；均势局优先修正一球差或平局 | 不得把一次失误机械外推为双方进球 |
| 上一场被射门20次以上且本场少打一人 | 大比分风险按非线性崩盘处理，上调第四球及以上 | 防线持续低位、替补深度不足或体能下降 |

每场最终输出必须包含至少一个极端比分尾部，并说明它只有在什么事件发生时才成立。

### 证据质量与结论一致性

- 排名只能支持基础实力，不能同时充当教练、替补深度、年龄结构和具体对位的证据。
- 同一维度的不同子检查项应有不同的具体发现；重复一段概括会掩盖真实未知。
- 如果“弱队第一球”为中或高，主比分区间中至少保留一个弱队进球比分；如果零封和强队第二球同时评为高，必须解释为何不会出现领先后收缩。
- 单场射门数据只作为近期状态，需结合射正质量、对手强度和长期风格回归判断。

## 二十三、球员状态评分表

每场比赛建议对双方核心球员做简短评分。

| 球员 | 位置 | 状态 | 类型 | 对位优势 | 风险 |
|---|---|---|---|---|---|
| A 队前锋 | 中锋 | 高 / 中 / 低 | 支点 / 终结 / 压迫 | 对中卫是否占优 | 体能 / 伤病 |
| A 队边锋 | 边路 | 高 / 中 / 低 | 速度 / 突破 | 对边后卫是否占优 | 被包夹 |
| A 队中场 | 组织 | 高 / 中 / 低 | 控节奏 / 直塞 | 对后腰是否占优 | 被压迫 |
| A 队后腰 | 防守 | 高 / 中 / 低 | 拦截 / 覆盖 | 能否保护中卫 | 犯规风险 |
| A 队中卫 | 防守 | 高 / 中 / 低 | 防空 / 速度 | 能否防反击 | 转身慢 |
| A 队门将 | 门将 | 高 / 中 / 低 | 扑救 / 出球 | 能否稳定小比分 | 失误 |

评分建议：

| 分数 | 含义 |

| 2 分 | 状态或对位有隐患 |
| 1 分 | 明显短板，可能被针对 |

## 二十四、比分修正规则

| 情况 | 修正 |
|---|---|
| 强队排名高，但关键对位不占优 | 从大胜降为小胜或平局 |
| 弱队排名低，但有两处以上对位优势 | 上调弱队进球数 |
| A 队弱点正好被 B 队强项克制 | 给 B 队至少一球概率明显上调 |
| 强队核心球员状态低迷 | 降低第二球概率 |
| 强队巨星状态很好且健康 | 上调第三球概率 |
| 强队替补冲击强 | 上调 75 分钟后进球概率 |
| 弱队核心球员状态很好且首发 | 提高 1-1 / 2-2 / 1-2 |
| 弱队核心不首发或只能替补 | 降低双方进球，增加 2-0 / 3-0 |
| 双方都有明显进攻对位优势 | 总进球上调到 3-4 球 |
| 双方进攻强项都被对方防守克制 | 总进球下调到 0-2 球 |
| 强队高空优势明显 | 3-1 / 4-1 / 4-0 进入候选 |
| 对手门将或后场出球风险高 | 上调压迫进球、乌龙、补射概率 |

## 二十六、推荐分析流程

1. 确认赛程、开球时间、场地和最新阵容信息。
2. 评估球队整体实力，但只作为基础盘。
3. 逐个分析双方关键球员状态、实力、类型和是否首发。
4. 找出每条线的关键对位。
5. 判断球队 A 的弱点是否正好被球队 B 的强项克制。
6. 判断球队 B 的弱点是否也被球队 A 的强项克制。
7. 分析近期进球、失球、xG、射正、定位球和防守数据。
8. 单独评估强队第二球能力。
9. 单独评估强队第三球与大胜能力。
10. 单独评估弱队第一球和第二球能力。
11. 评估热门球队防守脆弱度与零封能力。
12. 加入比赛阶段、心理压力、环境、裁判和赛程变量。
13. 分析平局风险，尤其区分 1-1 和 2-2。
14. 用赔率和市场信息验证是否存在热门过热、低估弱队进球或低估强队第三球。
15. 输出主比分区间、首选比分、次选比分、极端比分尾部和事件情景改判。

## 二十七、简化判断公式

```text
基础胜负倾向 = 球队整体实力 + 近期状态 + 阵容完整度

总进球区间 = 双方进攻路径 + 防守脆弱度 + 比赛开放触发器

强队进球数 = 第二球能力 + 第三球能力 + 巨星超额能力 + 替补冲击 - 对手防守克制能力

弱队进球数 = 核心是否首发 + 进球路径 + 对手防守漏洞 + 定位球/反击优势

零封概率 = 强队控场能力 + 中场反抢 + 防线稳定 - 弱队核心威胁

具体比分 = 胜负倾向 + 总进球区间 + 平局风险类型 + 关键对位修正 + 事件触发修正
```

## 二十八、复盘校正规则

每场赛后必须记录预测误差类型，并更新权重。

| 误差类型 | 说明 | 下次修正 |
|---|---|---|
| 低估强队第三球 | 实际 3-0/3-1，预测 2-0/2-1 | 上调巨星、替补、下半场调整权重 |
| 低估强队第四球 | 实际 4-1，预测 3-1 | 上调高空错位、补时混战、门将失误权重 |
| 高估弱队进球 | 实际零封，预测 2-1 | 检查弱队核心是否首发、进攻是否只有名气没有路径 |
| 低估平局 | 实际 1-1/2-2，预测强队胜 | 上调弱队第二球和强队控场风险 |
| 高估强队大胜 | 实际小胜/平，预测 3球以上 | 检查强队射正率、破密防能力、核心健康 |
| 低估非常规进球 | 乌龙、点球、门将脱手、压迫抢断 | 增加事件触发器权重 |
| 低估红牌后的极端尾部 | 常态预测2-0/3-0，实际因一红或两红扩大到5球以上 | 将红牌改判写成独立情景，不受常态总进球上限约束 |
| 证据克隆导致假完整 | 不同子检查项复用同一段排名或首轮数据 | 降低置信度并补充针对性证据；无法补充则标记未知 |
| 结论内部不一致 | 弱队第一球为中高但主比分全是零封，或领先后收缩风险高却第二球评高 | 最终比分必须回查并服从维度结论 |

## 二十九、最终一句话原则

排名决定基础概率，球员状态、球员类型、风格克制和关键对位决定具体比分。世界杯单场波动很大：  

- 弱队能精准攻击强队软肋时，必须把 1-1、2-2 甚至爆冷纳入重点预测区间。  
- 强队拥有健康巨星、替补冲击和高质量下半场调整时，必须把 3-0、3-1、4-1 纳入重点预测区间。  
- 弱队核心攻击手不首发或进攻路径被切断时，不能机械给弱队一球，要提高强队零封概率。
